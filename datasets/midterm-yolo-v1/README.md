# 中期检查 YOLOv8n 六形状数据集 v1

本目录包含首轮候选图片与对应的 YOLO 检测框标签：196 张训练图、40 张验证图，共 236 张（其中 10 张空盘配同名空标签），256 个目标框。六类 ID 依次为 `cube, sph, cyl, tpri, cone, tet`。颜色不作为 YOLO 类别。

`data.yaml` 使用本目录相对路径，可在仓库克隆后的不同电脑上使用。`splits.csv` 记录每张图的 train/val 及摆放编号；`selection.csv` 记录从原电脑 698 张候选照片中选取的来源。原电脑其余未标注照片和原始 AnyLabeling JSON 未包含在此数据集。此前导出的类别顺序为 `cone, cube, cyl, sph, tet, tpri`，已按类名重映射到本目录的固定顺序。

当前仅完成数据准备，尚未训练或验证模型，也未建立最终独立测试集。空盘的标签文件为空是预期格式。

本批 10 张多件图共 40 个框，当前仅覆盖正方体与圆柱体的组合；其他四形状虽有单件训练样本，但多件场景还未覆盖。后续若演示中会同时出现六形状，应补标已有混合原图并重新划分。
