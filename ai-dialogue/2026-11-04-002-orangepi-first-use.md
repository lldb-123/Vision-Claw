## 决策与连接方法

- 使用板卡对应的 Ubuntu/Debian 等 Linux 系统；“支持 Linux”不代表该实物已经安装 Linux。已有系统时先沿用；无系统时再准备对应型号镜像与启动介质。
- 香橙派网口接路由器 LAN 口；Windows 笔记本连接同一路由器的 Wi-Fi 或网线，避免访客网络的设备隔离。
- 香橙派独立供电。按香橙派 5 厂商手册，应使用 5V/4A Type-C 电源，并识别供电口；不依赖笔记本 USB 口供电。
- 系统启动并开启 SSH 后，可从路由器已连接设备列表查板卡 IP。在 Windows PowerShell 使用 `ssh 用户名@板卡IP`；账号与密码以实际系统为准，不猜测用户凭据。
- 登录后可用 `python3 --version` 检查 Python，再用 `python3 -c "print(123 + 456)"` 演示计算，预期输出 `579`。这些命令只是操作示例，本轮没有在板上执行。
- 后续可把计算逻辑保存为 `calc.py`，在香橙派执行 `python3 calc.py`。
