### 当前使用的接线方案

| A4988 引脚 | 连接 |
| --- | --- |
| VDD | STM32 3V3 |
| 逻辑 GND | STM32 GND |
| STEP | STM32 PA0 |
| DIR | STM32 PA1 |
| EN | STM32 PA4，低电平使能；不能同时接 GND |
| RESET、SLEEP | 3V3 |
| MS1、MS2、MS3 | GND，整步模式 |
| 1A、1B | 电机的一组线圈 |
| 2A、2B | 电机的另一组线圈 |
| VMOT | 电机电池主电源正极，经开关线 |
| VMOT 旁电源 GND | 电池负极，与 STM32 共地 |

ST-Link：SWDIO/DIO → STM32 PA13/SWDIO，SWCLK/CLK → PA14/SWCLK，GND → GND。

引脚按丝印名称识别，PA13/PA14 不是“排针第 13/14 个”。ST-Link 的 SWIM 不是 SWDIO。开发板自己 USB 供电时，ST-Link 输出电源不再并接；独立 VTref 输入与输出电源是不同概念。

这张表记录的是本实验约定接线，不代表助手逐根看过实物。已确认的实物结果是：旧版程序能按预期让电机沿同一方向走一小段。

### 电源和限流的未确认事项

- 清单写 6S 电池，用户实际电池铭牌与完整规格没有核实；不要用之前对平衡插头孔数的描述反推确定型号。
- 电池应取 XT60 主输出，不从平衡插头给电机供电。电池主电压不能接 STM32 的 3V3/5V。
- A4988 的采样电阻标识、Vref 和实际限流值没有测定。本固件只生成运动脉冲，不负责电流限制。
- 之前建议 VMOT 附近加合适的电源电容，但对实物电容安装与容量没有单独得到确认。
- 改电机接线应先断电，不能带着电机电源拔插线圈。后续按实际操作需要简明提醒，不重复用整套校验阻挡普通实验。

## 8. 单电机固件最新行为

### 旧版：已被替换

- 等待约 1 秒后发 20 个脉冲，每秒约 20 个，随后 EN 置高、关闭输出。
- 用户反馈“小幅度旋转、抖动”，追问后明确为“同一方向边转边顿挫，然后停止”，不是原地左右来回摆。
- 该表现符合旧版脉冲少、速度低的程序。用户真正要的是持续正常旋转，因此不能把旧版短时动作当成最终交付。

### 当前版：已烧录，持续旋转实物反馈待确认

- 裸机 Cortex-M4 汇编，不依赖 HAL、外部晶振或完整 IDE。
- 使用内部 HSI 16MHz，SysTick 轮询产生毫秒延时。
- PA0=STEP，PA1=DIR，PA4=EN，保留 PA13/PA14 的 SWD 配置。
- 启动先禁用驱动，等待约 1 秒；使能后等待 5ms。
- STEP 高电平 1ms；低电平从 19ms 分档下降至 4ms，即从 50Hz 逐渐加速到 200Hz，过程约 2 秒。
- 达到 200Hz 后保持同一方向持续输出，没有自动停止。
- 若电机为 1.8°、接线为整步，理论稳定速度约 60 转/分钟；其他步距角或细分设置会改变转速。
- 按 RESET 会重新启动上述过程，不能拿 RESET 当停止键。停止请断开电机电池。
- 该固件不包含回零、限位、机构位置控制、串口命令或整机分拣流程。

用户上一次收到的实际操作说明是：接通电机电池，按一下开发板 RESET，等待约 1 秒后起转，逐渐加速，然后持续旋转；停止则断开电机电池。

### 连接问题已解决

曾出现 `Error: init mode failed (unable to connect to the target)`。当时 Windows 已识别 ST-Link，问题发生在连接 STM32 的阶段，没有开始写 Flash。随后脚本改用原生 SWD、100kHz，用户重新给 STM32 供电后，实际连接和烧录成功。

不要在没有新证据时重新安装驱动、升级 ST-Link 或继续排查已经解决的连接问题。

### 最新实际日志结果

```text
SWD DPIDR 0x2ba01477
Cortex-M4 r0p1 processor detected
device id = 0x10076413
flash size = 512 KiB
** Programming Finished **
** Verified OK **
Firmware ready. CPU halted, EN high. Press board RESET to start continuous rotation.
```

### 已做的软件验证

这是 CPU/GPIO 序列和模拟计时验证，不是实际示波器测量，也不能证明真实限流、扭矩、温升或不丢步。

## 14. 原电脑上的构建、检查与下载方法

下面命令用于原 Windows 电脑桌面实验目录。新电脑只克隆本次文档仓库后，不会自动获得该实验目录或虚拟环境。

```powershell
Set-Location -LiteralPath 'C:\Users\Lenovo\Desktop\单电机试转'

# 修改汇编后重新生成固件。
& '.\.venv\Scripts\python.exe' '.\build_firmware.py'

# 检查模拟的脉冲、加速及 GPIO 行为。
& '.\.venv\Scripts\python.exe' '.\check_firmware.py'

# 下载及校验；接线沿用本记录。操作前断开电机电池，保留板子 USB 和 ST-Link。
& '.\flash_motor.ps1'
```

下载成功后：接通电机电池，按开发板 RESET 启动持续旋转；停止断开电机电池。日常重复运行不需要再次烧录，按 RESET 会重新执行当前固件。

下载配置保留低 SWD 速度的原因是：OpenOCD 默认 STM32F4 目标脚本在复位初始化期间会调整时钟和下载速度；当前实验覆盖相关事件，保持 100kHz，使用已经成功的连接参数。
