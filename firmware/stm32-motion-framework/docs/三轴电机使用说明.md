# VisionClaw STM32 三轴电机使用说明

本文适用于当前 STM32F407VET6 运动控制固件：

- X/Y：两台 42 步进电机，A4988 驱动。
- Z：MG90S 舵机。
- USART2：115200、8N1、无流控。
- 当前源码：`d3f4994` 加本地 X/Y 上电禁用、`CLEAR` 成功禁用 X/Y 的安全修改。

> 本文以当前本地源码为准。提交到团队仓库前，应再次确认远端分支和实际烧录 HEX 的版本。

## 1. 安全规则

1. A4988 通电时不要插拔电机线。
2. 测试前确认 STM32 GND、A4988 逻辑 GND 和 12V 电源 GND 正确共地。
3. 首次测试使用低速、短距离，并先脱开机械负载。
4. 不要用 STM32 的 3.3V 给电机或舵机功率端供电。
5. 急停输入 PB4 为低有效。正常时 PB4 应为高电平。
6. 当前固件不再使用物理限位开关，必须依靠约 `0～200mm` 的软件坐标范围限制。
7. 上机标定前必须人工确认机械有效行程，避免软件范围大于真实行程。
8. `HOME` 或 `SET_ZERO` 会把当前位置直接设为零，使用前必须确认机构位于人工认定的原点。

## 2. 接线

| 功能 | STM32 引脚 | 说明 |
|---|---|---|
| X STEP | PA0 | 脉冲输出 |
| X DIR | PA1 | 方向输出 |
| X ENABLE | PA4 | 低有效，高电平禁用 |
| Y STEP | PA2 | 脉冲输出 |
| Y DIR | PA3 | 方向输出 |
| Y ENABLE | PA5 | 低有效，高电平禁用 |
| Z / MG90S PWM | PA6 / TIM3_CH1 | 50Hz |
| ESTOP | PB4 | 低有效，内部上拉 |
| USART2 TX | PD5 | 接 USB-TTL RX |
| USART2 RX | PD6 | 接 USB-TTL TX |

可选分类转盘舵机：

| 功能 | STM32 引脚 | 说明 |
|---|---|---|
| DS3120MG #1 | PC7 / TIM3_CH2 | 50Hz |
| DS3120MG #2 | PC8 / TIM3_CH3 | 50Hz |

当前固件不读取 PB0、PB1、PB3、PB6。即使这些引脚上仍接有原来的限位开关，也不会参与运动停止判断。

## 3. 上电状态

当前安全版本上电后：

- PA4 为高，X A4988 默认禁用。
- PA5 为高，Y A4988 默认禁用。
- MG90S PWM 初始化，默认 1500us。
- X/Y 必须收到明确的 `ENABLE X` 或 `ENABLE Y` 后才使能。
- `ENABLE ALL` 会同时使能 X/Y，并启用 Z 舵机。

上电后可先发送：

```text
STATUS
```

预期 X/Y 的 `enabled=0`，Z 的 `enabled=1`。

## 4. 推荐的首次测试顺序

### 4.1 确认串口和状态

串口设置为：

```text
115200
8 数据位
1 停止位
无校验
无流控
```

每条命令以回车或换行结束。发送：

```text
STATUS
```

### 4.2 清除旧故障

```text
CLEAR
```

成功后，X/Y 的 PA4、PA5 都会被拉高，两轴保持禁用。`CLEAR` 不会自动重新使能 X/Y。

### 4.3 单独使能 X 轴

```text
ENABLE X
STATUS
```

确认 X 轴显示：

```text
enabled=1
```

此时 PA4 应为约 0V。Y 轴仍应保持 `enabled=0`。

### 4.4 小距离 X 轴点动

```text
MOVE X 100 200
```

- `100`：相对移动 100 个脉冲。
- `200`：最高 200 脉冲/秒。
- 当前换算为 80 脉冲/mm，因此约移动 1.25mm。

移动结束后查询：

```text
STATUS
```

### 4.5 单独使能 Y 轴

```text
ENABLE Y
STATUS
```

确认 Y 轴 `enabled=1`。此时 PA5 应为约 0V。

```text
MOVE Y 100 200
```

### 4.6 建立软件零点

当前没有物理限位开关，因此 `HOME` 不再驱动电机寻找开关，而是在当前位置直接建立软件零点。对应轴必须先使能：

```text
HOME X
HOME Y
```

也可以在两轴均使能后执行：

```text
HOME ALL
```

`HOME`、`SET_ZERO` 的当前含义都是：

- 将当前位置设为 `0`。
- 将 `homed` 设为 `1`。
- 不产生任何运动脉冲。

执行前必须人工确认当前位置可以作为机械原点。随后查询：

```text
STATUS
```

软件零点建立后的标志为：

```text
state=0
homed=1
pos_steps=0
```


## 5. X/Y 运动命令

### 相对运动

相对运动不要求预先回零，但结果必须位于当前软件行程 `0～200mm` 内：

```text
MOVE X 800 400
MOVE Y -800 400
MOVE X -800 400
```

参数格式：

```text
MOVE <X|Y> <相对脉冲数> <脉冲/秒>
```

速度范围为 100～12000 脉冲/秒。

毫米相对运动：

```text
MOVE_MM X 10 5
MOVE_MM Y -10 5
```

参数格式：

```text
MOVE_MM <X|Y> <相对毫米> <毫米/秒>
```

### 绝对运动

绝对运动要求对应轴已经通过 `HOME` 或 `SET_ZERO` 建立坐标：

```text
GOTO X 800 400
GOTO Y 800 400
GOTO_MM X 100 5
GOTO_MM Y 80 5
```

未建立软件零点时使用 `GOTO` 或 `GOTO_MM` 会返回：

```text
ERR X_NOT_HOMED
```

或：

```text
ERR Y_NOT_HOMED
```

### 坐标范围

当前配置：

```text
X_STEPS_PER_MM = 80
Y_STEPS_PER_MM = 80
X_MIN_MM = 0
Y_MIN_MM = 0
X_MAX_MM = 200
Y_MAX_MM = 200
软件最大位置 = 16000 脉冲
```

80 脉冲/mm 是开发默认值，必须按实际细分数和丝杆导程校准。

## 6. Z 轴与舵机命令

```text
Z UP
Z DOWN
SERVO Z 1600 1000
STOP Z
```

- `Z UP`：当前配置为 2500us。
- `Z DOWN`：当前配置为 500us。
- `Z UP`、`Z DOWN` 默认平滑时间为 700ms。
- MG90S 允许 500～2500us。

分类转盘舵机：

```text
SERVO 1 1500 500
SERVO 2 1500 500
```

- DS3120MG #1、#2 当前允许 1000～2000us。
- 每路舵机最多排队 16 条动作。
- `STOP Z` 只停止 Z 并清空 Z 的待执行队列。
- `STOP ALL` 停止 X/Y，并停止 MG90S、清空 Z 队列。
- 舵机没有位置反馈，`busy=0` 只表示 PWM 过渡结束，不代表机构到位。

## 7. XYZ 组合命令

相对组合运动：

```text
MOVE_XYZ <dx_mm> <dy_mm> <z_us> <速度_mm/s> [z_ms]
```

示例：

```text
MOVE_XYZ 20 20 2500 10
MOVE_XYZ -20 -20 500 10 700
```

相对组合运动不要求预先回零，但 X/Y 的目标位置仍必须位于 `0～200mm` 内。

绝对组合运动：

```text
GOTO_XYZ <x_mm> <y_mm> <z_us> <速度_mm/s> [z_ms]
```

示例：

```text
GOTO_XYZ 100 80 2500 15
```

`GOTO_XYZ` 要求参与运动的 X/Y 轴已经通过 `HOME` 或 `SET_ZERO` 建立软件零点。Z 参数始终使用脉宽 `us`，不是毫米或角度。

## 8. 状态解释

示例：

```text
STATUS X pos_steps=800 pos_mm=10.00 target=800 state=0 enabled=1 homed=1
```

状态码：

| state | 含义 |
|---:|---|
| 0 | 空闲 |
| 1 | 普通运动 |
| 2 | 正在回零 |
| 3 | 限位停止 |
| 4 | 急停锁存 |
| 5 | 故障 |

`ACK` 表示命令被接受，不代表运动已完成。运动是否结束应通过 `STATUS` 判断。

## 9. 停止、急停和恢复

减速停止：

```text
STOP X
STOP Y
STOP ALL
```

软件急停：

```text
ESTOP
```

`ESTOP` 会：

- 停止 X/Y 脉冲。
- 将 PA4、PA5 拉高，禁用两个 A4988。
- 锁存 X/Y 和舵机急停状态。

物理急停 PB4 被拉低时，TIM6 中断也会停止运动并禁用 X/Y。

急停释放后：

```text
CLEAR
STATUS
```

`CLEAR` 成功后：

- 清除 X/Y 和舵机故障锁存。
- 将 PA4、PA5 拉高，确保 X/Y 仍保持禁用。
- 不会自动恢复运动。

需要重新使能：

```text
ENABLE X
ENABLE Y
```

或：

```text
ENABLE ALL
```

## 10. 常见错误

| 返回 | 含义 |
|---|---|
| `ERR AXIS_DISABLED` | 对应 A4988 尚未使能 |
| `ERR X_DISABLED` / `ERR Y_DISABLED` | XYZ 组合命令所需的轴未使能 |
| `ERR X_NOT_HOMED` / `ERR Y_NOT_HOMED` | 使用了绝对运动命令，但尚未建立零点 |
| `ERR X_BUSY` / `ERR Y_BUSY` | 对应轴正在运动或回零 |
| `ERR X_FAULT` / `ERR Y_FAULT` | 对应轴处于故障状态，需要先 `CLEAR` |
| `ERR ESTOP_ACTIVE` | 急停仍有效或急停状态尚未清除 |
| `ERR SPEED` | 速度超出允许范围 |
| `ERR RANGE` | 位移、坐标或脉宽越界 |
| `ERR FORMAT` | 参数数量、轴名称或数字格式错误 |
| `ERR REJECTED` | 通过预检查后，启动阶段仍被状态变化或底层条件拒绝 |

## 11. “位置在变但电机不转”的排查

`pos_steps` 是根据输出脉冲计算的软件坐标。它会变化，不代表电机真的转动。

按以下顺序检查：

1. `ENABLE X` 或 `ENABLE Y` 后，电机是否有保持力矩。
2. 对应 EN 引脚对 GND 是否约为 0V。
3. 运动时 STEP 引脚是否有脉冲输出。
4. A4988 的 VMOT 是否为稳定的 12V。
5. VDD、RESET、SLEEP、VREF 是否正常。
6. 电机两组线圈是否分别正确接到 `1A/1B` 和 `2A/2B`。
7. 脱开机械负载后电机轴是否能转动。

如果 A4988 严重发热且电机没有保持力矩，应立即断电，不要继续让程序发 STEP 脉冲。

## 12. 推荐的安全停机顺序

1. 停止正在执行的运动。
2. 发送 `ESTOP` 或触发物理急停。
3. 关闭 A4988 VMOT 12V。
4. 等待模块冷却。
5. 需要重新测试时，先发送 `CLEAR`。
6. 单独使能一个轴并进行短距离测试。

## 13. 当前验证边界

- X/Y 两轴 A4988 控制已有实物运动记录。
- 旧版本 Y 轴已有实物回零记录；当前无物理限位版本改为软件零点，不再执行寻边回零。
- MG90S 已通过串口实测运动。
- 两台 DS3120MG 仍需实物验证。
- 当前 A4988 出现过严重发热和无保持力矩现象，必须先排除功率与接线故障。
- 完整自动分拣流程和 Orange Pi 正式联调尚未完成。
