# STM32F407 双轴步进运动控制初版设计

## 目标
为智能分拣系统提供可移植的双轴步进运动控制基础模块，运行在 STM32F407，使用 HAL API，可接入 STM32CubeIDE/CubeMX 工程。

## 硬件假设
- 两路 A3967 驱动板，每路使用 STEP、DIR 信号。
- ENABLE/SLEEP 暂按驱动板默认有效状态处理，不占用 MCU 引脚；后续可扩展为 GPIO 控制。
- 电机为 1.8° 两相步进电机，额定电流约 1.5 A。
- 默认细分参数为 1/8，对应 1600 脉冲/转；通过宏可改为 200/400/800/1600/3200 等值。
- 每轴提供正/负限位输入；另设急停输入。

## 软件结构
- `motion_axis.[ch]`：轴状态、位置、目标、速度、加速度、限位状态。
- `stepper_timer.[ch]`：基于一个高频定时器中断调度两轴 STEP 脉冲。
- `motion_control.[ch]`：双轴动作接口、停止、急停、回零和状态查询。
- `motion_protocol.[ch]`：UART 行命令解析，提供 MOVE、HOME、STOP、ESTOP、STATUS。
- `main.c`：初始化和最小演示；实际 GPIO/TIM/UART 句柄由 CubeMX 生成。

## 运动模型
- 每轴采用位置模式：目标位置为脉冲数，方向由目标与当前位置差决定。
- 速度单位为 pulses/s，加速度单位为 pulses/s²。
- 使用梯形速度曲线，低速启动并在接近目标时减速。
- 定时器中断周期建议 10~20 µs；STEP 高电平宽度默认 5 µs，满足 A3967 常见时序要求。
- 轴达到目标或触发限位后停止脉冲并更新状态。

## 安全行为
- 急停输入有效时立即关闭两轴 STEP，动作状态置为急停。
- 限位输入有效时停止对应方向运动；反向脱离限位仍允许。
- 上电不自动运动，需显式发送命令。
- 参数非法、命令格式错误或轴忙时返回错误码。

## UART 命令
- `MOVE X <steps> <speed>`：相对移动。
- `GOTO X <position> <speed>`：绝对移动。
- `HOME X`：按配置方向低速回零，触发限位后清零。
- `STOP X`：减速停止单轴。
- `ESTOP`：立即停止全部轴。
- `STATUS`：返回位置、目标、速度和故障状态。

## 验证范围
- 编译级验证：源码可被 STM32CubeIDE 工程直接加入并通过编译（句柄名按示例配置）。
- 台架验证：单轴正反转、双轴同时运动、限位停止、急停、串口命令。
- 由于尚未取得实际接线表和完整机构尺寸，默认 GPIO/TIM/UART 只提供示例映射，需现场按原理图修改。
