# 香橙派上位控制程序设计

## 目标
在香橙派上提供一个可触摸操作的网页控制台，并通过 USART2/115200 8N1 控制 STM32F407 三轴运动、舵机和底部托盘。

## 架构
- `controller.py` 提供串口抽象、命令队列、状态轮询、文本协议解析和模拟设备。
- `server.py` 提供标准库 HTTP 服务、JSON API 和嵌入式单页界面。
- 真实设备优先使用 `pyserial`，串口打开失败时自动进入模拟模式，便于联调。
- 状态以线程安全快照保存，网页每秒轮询 `/api/state`。

## 命令与安全
所有动作命令串行发送并等待 STM32 回复。急停直接发送 `ESTOP`。绝对定位由固件负责回零和限位校验。界面明确显示 Z 无位置反馈、托盘为开环控制。

## 验证
在无串口环境运行模拟模式，检查首页、状态 API、命令 API、错误反馈和急停流程。接入真实 STM32 后通过配置 `serial_device` 验证串口回复。
